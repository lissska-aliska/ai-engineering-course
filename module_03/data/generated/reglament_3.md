## **Содержание документа**

### 1. Цель и область применения

Определяются цели и задачи данного регламента, устанавливаются требования к действиям персонала при возникновении инцидентов на технологических установках.

### 2. Термины и определения

Приводятся основные термины и понятия, используемые в данном регламенте.

### 3. Организация реагирования на инциденты

#### 3.1. Порядок действий персонала при обнаружении инцидента
- Ответственный за принятие решения: инженер по безопасности производства
- Пороговое значение температуры аварийной остановки: +120 °C
- Сроки проведения первичного осмотра после инцидента: не позднее 1 часа
- Форма уведомления руководства: служебная записка по форме РГЛ-Ф-03

#### 3.2. Действия дежурного оператора
- Обязанность немедленно уведомить старшего смены и инженера по эксплуатации
- Максимальное время реакции на критическое отклонение параметра: 1 минута
- Инцидент фиксируется в журнале регистрации инцидентов по форме РГЛ-Ф-08

### 4. Документация и отчетность

#### 4.1. Регистрация инцидентов
- Формирование акта расследования инцидента по форме РГЛ-Ф-04
- Срок предоставления отчета о расследовании инцидента: 3 рабочих дня
- Перечень лиц, участвующих в расследовании: инженер по охране труда, главный инженер

#### 4.2. Анализ инцидентов
- Проведение анализа причин возникновения инцидента ежеквартально комиссией
- Отчет о результатах анализа направляется руководству предприятия ежемесячно

### 5. План мероприятий по предотвращению инцидентов

#### 5.1. Проведение инструктажей и тренировок
- Ежегодное проведение учений по ликвидации последствий инцидентов
- Регулярность инструктажей по технике безопасности: не менее одного раза в квартал

#### 5.2. Контроль состояния технологического оборудования
- Плановая проверка исправности системы сигнализации: не реже одного раза в месяц
- Назначение ответственного лица за контроль состояния оборудования: старший мастер цеха

### 6. Исключения и особые случаи

#### 6.1. Отсутствие необходимых приборов контроля
При выходе из строя измерительных приборов решение о дальнейших действиях принимает инженер по эксплуатации

#### 6.2. Работы вне графика планово-предупредительного ремонта
Требования к таким работам определяются отдельным регламентом РГЛ-ХХ-001

#### 6.3. Неопределенность типа оборудования
Решение о дальнейших действиях принимается инженером по эксплуатации индивидуально
